# 回声

基于 AstrBot 的中文群聊插件，提供 @ 唤醒、按概率接话与定时提醒。消息历史与提醒按群隔离。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/帮助` | 命令列表 |
| `/待办` | 列出本群未完成的提醒 |
| `/提醒 内容` | 按描述的时间 @ 发起人 |

群里 @ 机器人必定回复；未 @ 时按 `reply_chance` 概率接话。插件仅处理群消息。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `api_key` | 空 | 模型凭据；留空使用内置模拟回复 |
| `api_base` | `https://api.openai.com/v1` | OpenAI 兼容接口地址 |
| `model` | `gpt-4o-mini` | 模型 ID |
| `reply_chance` | `20` | 非 @ 消息接话概率（%） |
| `persona` | 内置人设 | 系统提示词 |
| `reminder_enabled` | `true` | 定时提醒开关 |

配置 `api_key` 后，`/提醒` 支持自然语言写法，由模型解析并校验后创建。修改配置后需重载插件。
